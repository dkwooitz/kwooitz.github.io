# kwooitz.co.za

Personal site for Diedrik Kwooitz, management accountant (aspiring ACMA, CGMA).

The page is a CV with a section on apps I have built: Capital Management, Car-diology and my wedding website.

It is one static file, `index.html`, built with HTML, CSS and JavaScript. It has no build step and no dependencies other than Google Fonts.

## Run locally

Open `index.html` in a browser.

## Publish

Served by a Cloudflare Worker at **https://kwooitz.co.za**, deployed from `main`.
