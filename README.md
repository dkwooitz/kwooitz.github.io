# dkwooitz.github.io

Personal site for Diedrik Kwooitz, management accountant (aspiring ACMA, CGMA).

The page is a CV with two working management-accounting tools built in:

- **Break-even and CVP analyser**: live break-even chart, margin of safety, C/S ratio and operating leverage.
- **Material variance calculator**: price, usage and total variances with CIMA-style F/A flags and a plain-English reading.

It is one static file, `index.html`, built with HTML, CSS and JavaScript. It has no build step and no dependencies other than Google Fonts.

## Run locally

Open `index.html` in a browser.

## Publish

This repo is a GitHub user site, so it is served at **https://dkwooitz.github.io** from `main` / root (Settings → Pages).
